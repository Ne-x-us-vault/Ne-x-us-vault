### Featured Projects

**[Nexus Launcher](https://github.com/Ne-x-us-vault/custom-launcher-nexus)**

A frost-glass, keyboard-first GNOME Shell application launcher with instant app search, arrow-key navigation, and quick actions for Terminal, Files, GitHub, and LinkedIn.

**[Bio-Byte AI](https://github.com/Ne-x-us-vault/Bio-Bytes)**

Two-feature Android app built at PEC Hacks 4.0: an offline NFC/HCE emergency medical ID with QR fallback that works with no backend dependency, and an AI ambient scribe that turns doctor-patient conversations into SOAP notes via an STT + LLM pipeline.

**DualCore**

A bolt-on ethanol-diesel dual-fuel retrofit kit for Indian MSME diesel gensets in the 30–125 kVA range. Fuels stay in separate tanks with combustion-chamber-only mixing via port injection — no pre-blending, sidestepping flash-point compliance issues.

**AI Hallucination Detection & Reliability Scoring**

Built for HackWithAMYPO National Hackathon 2026: an NLI-entailment and self-consistency pipeline (DeBERTa-v3-MNLI + a quantized Mistral/Llama-class generator) that scores LLM outputs for reliability, with a React + FastAPI + FAISS + PostgreSQL stack.
